# Лабораторные работы по компьютерной графике — Vulkan

Работы выполнены на Vulkan, GLFW и ImGui. Каждая лабораторная сохранена в отдельной ветке, а `main` содержит последнюю выполненную работу.

Актуальная версия: **ЛР №3 «Текстурирование», вариант 9 — конус**. Выполнены базовое задание и дополнительные задания №1–2 для оценки 4. Последнее дополнительное задание со specular- и emissive-текстурами не реализовано.

## Что реализовано в ЛР №3

- Два экземпляра конуса с общей геометрией и независимыми преобразованиями и материалами.
- Процедурные UV-координаты боковой поверхности и круглого основания.
- Загрузка трёх PNG с диска через stb_image: Grass, Night stars и Water. Текстура задаёт альбедо вместо сплошного или вершинного цвета.
- Отдельный набор дескрипторов для каждого материала: общий динамический uniform-буфер свойств моделей и combined image sampler.
- Выравнивание записей моделей по `minUniformBufferOffsetAlignment`; выбор записи динамическим смещением при привязке дескрипторов.
- Вершинные и индексные буферы, а также изображения в device-local памяти GPU; загрузка через staging-буферы и команды копирования.
- Эффект первого конуса: два чтения одной текстуры с разными движущимися UV, смешивание и модуляция цвета от времени. Время и флаг эффекта передаются через push-константы.
- Сохранены камера, освещение Блинн–Фонга, точечные источники, прожекторы и их визуализация из ЛР №2.

## Сборка и запуск в Windows

Нужны Visual Studio 2022 с компонентами C++, CMake, Git и Vulkan SDK с `glslc`. При первой сборке необходим Интернет для загрузки зависимостей; их версии закреплены в CMake.

```powershell
git clone --branch LR_3 https://github.com/Ivan00700/Vulkan_Laboratory_works.git
cd Vulkan_Laboratory_works
.\build.cmd
.\run.cmd
```

Для актуальной версии можно клонировать репозиторий без `--branch`: будет выбрана `main`.

`build.cmd` использует переменную `VULKAN_SDK`; если она не задана, проверяет `C:\VulkanSDK\1.4.363.0`. Укажите путь к установленному SDK, если он отличается. Сборка создаёт `build-debug/Debug/vulkan-starter-app.exe` и компилирует шейдеры в `shaders/*.spv`.

`run.cmd` устанавливает рабочий каталог проекта, откуда загружаются текстуры и шейдеры. Перед повторной сборкой закройте приложение, чтобы Windows разрешила заменить EXE.

## Управление

В разделе **Textures**:

- **Selected model** — конус, параметры которого редактируются.
- **Albedo texture** — независимый выбор Grass, Night stars или Water для выбранного конуса.
- **Animated sampling (cone 1)** — эффект первого конуса, независимо от выбранной модели. При отключении оба конуса используют обычное однократное сэмплирование.

Перетаскивание левой кнопкой мыши вне панели вращает выбранный конус. Раздел **Object** задаёт его положение, поворот и масштаб. **Camera** управляет общей камерой; остальные разделы — освещением и его визуализацией.

## Замена текстур

Рабочие файлы: `textures/grass.png`, `textures/night-stars.png`, `textures/water.png`.

Загрузчик поддерживает настоящий PNG. Переименование JPEG, WebP или AVIF в `.png` не преобразует изображение. При замене содержимого PNG с прежним именем достаточно перезапустить приложение. При изменении имён файлов обновите `texture_paths` и `texture_names` в `source/application.cpp`, затем пересоберите проект.
