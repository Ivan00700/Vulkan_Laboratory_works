# Лабораторная работа №1 — конус

Приложение на **Vulkan, GLFW и ImGui** отображает объёмный конус (вариант 9) с проверкой глубины и простым освещением. Выполнена базовая часть и первые пять дополнительных заданий на оценку 4.

Конус состоит из 48 боковых и 48 нижних треугольников. В окне ImGui можно переключить перспективную и ортографическую проекции, изменить позицию, поворот, масштаб и цвет. Анимация перемещает и поворачивает конус по пространственной траектории; доступны пауза, скорость и радиус. Цвет каждой вершины вычисляется из её локальных координат и умножается на выбранный цвет. Левой кнопкой мыши также можно вращать конус, колесом — менять масштаб просмотра.

## Сборка и запуск в Windows

Нужны Visual Studio с компилятором C++, CMake и Vulkan SDK с `glslc`. Из корня проекта запустите:

```powershell
.\build.cmd
.\run.cmd
```

При первой сборке CMake загрузит зависимости. Запускайте приложение из корня проекта: там оно ищет скомпилированные шейдеры.

## Где находится реализация

- `source/application.cpp` — геометрия конуса, Vulkan-буфер, графический конвейер, управление и команды рисования.
- `shaders/cone.vert` — трансформации и выбор проекции.
- `shaders/cone.frag` — процедурный цвет вершин, выбранный цвет и освещение.
- `CMakeLists.txt` — сборка приложения и компиляция GLSL-шейдеров в SPIR-V.

Проект основан на [vulkan-starter-app](https://github.com/vladeemerr/vulkan-starter-app).
