# Лабораторные работы по компьютерной графике — Vulkan

Лабораторные работы распределены по отдельным веткам `LR_1`, `LR_2`, … . Каждая ветка содержит код соответствующей работы и свой README с её описанием, управлением и инструкцией по сборке.

Ветка **main** содержит актуальную полную версию проекта — последнюю выполненную лабораторную работу. Сейчас это **лабораторная работа №2 «Камера и освещение»**, выполненная на оценку 5.

## Текущая реализация

Приложение на **Vulkan, GLFW и ImGui** отображает конус — вариант 9. Геометрия, нормали и цвет вершин генерируются процедурно.

- Камера: положение, поворот, угол обзора, ближняя и дальняя плоскости отсечения.
- Материал Блинн–Фонга: альбедо, цвет и резкость блика; направленное и фоновое освещение.
- Динамические массивы точечных источников и прожекторов в storage-буферах, добавление и удаление через ImGui.
- Затухание точечных источников и прожекторов по закону обратных квадратов, мягкие края прожекторов между внутренним и внешним углами.
- Отдельные наборы дескрипторов сцены и модели.
- Цветные кубики источников, белые оси и контуры прожекторов; показ и скрытие визуализации независимо от освещения.
- Вращение конуса перетаскиванием левой кнопкой мыши вне панели ImGui.

Подробности текущей лабораторной, параметры интерфейса и устройство буферов описаны в [README ветки LR_2](https://github.com/Ivan00700/Vulkan_Laboratory_works/blob/LR_2/README.md).

## Сборка и запуск в Windows

Нужны Visual Studio 2022 с компилятором C++, CMake и Vulkan SDK с `glslc`. Из корня проекта:

```powershell
.\build.cmd
.\run.cmd
```

При первой сборке CMake загружает зависимости. `build.cmd` использует переменную `VULKAN_SDK`, а если она не задана — `C:\VulkanSDK\1.4.363.0`. `run.cmd` выбирает рабочую папку проекта, где находятся скомпилированные шейдеры.

Чтобы получить конкретную лабораторную при клонировании:

```powershell
git clone --branch LR_2 https://github.com/Ivan00700/Vulkan_Laboratory_works.git
```

Для первой работы заменить `LR_2` на `LR_1`. Без выбора ветки клонируется `main` с актуальной полной версией.

## Основные файлы

- `source/application.cpp` — геометрия, камера, интерфейс, буферы света, визуализация и команды отрисовки.
- `source/graphics_internal.cpp` — Vulkan-контекст, swapchain, глубина и синхронизация.
- `shaders/cone.vert`, `shaders/cone.frag` — преобразования объекта и освещение.
- `shaders/marker.vert`, `shaders/marker.frag` — визуализация источников постоянным цветом.
- `CMakeLists.txt` — зависимости, сборка приложения и компиляция шейдеров.

Исходный каркас проекта: [vulkan-starter-app](https://github.com/vladeemerr/vulkan-starter-app).
